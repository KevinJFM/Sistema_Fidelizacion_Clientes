# Backend — Sistema de Fidelización de Clientes

API construida con Node.js + Express.

## Estructura

```
src/
├── config/        Configuración del proyecto
├── controllers/   Manejo de las peticiones
├── helpers/       Funciones auxiliares
├── middlewares/   Funciones intermedias
├── models/        Definición de los modelos
├── routes/        Definición de las rutas
├── seeds/         Datos iniciales del proyecto
├── services/      Lógica del negocio
├── utils/         Funciones reutilizables
├── validators/    Validación de datos
├── app.js         Configuración de Express
└── server.js      Punto de entrada
uploads/           Archivos subidos
```

## Scripts

```bash
pnpm install
pnpm dev
```
