# Frontend — Sistema de Fidelización de Clientes

Aplicación construida con React + Vite.

## Estructura

```
src/
├── api/          Conexión con el backend
├── assets/       Archivos estáticos
├── components/   Componentes reutilizables
│   ├── layout/
│   └── ui/
├── context/      Gestión de estado global
├── data/         Contenido estático
├── hooks/        Lógica personalizada
├── pages/        Páginas de la aplicación
│   ├── Admin/
│   ├── Auth/
│   ├── Home/
│   ├── Shop/
│   └── User/
├── redux/        Gestión avanzada del estado
├── services/     Lógica del frontend
└── utils/        Funciones de utilidad
```

## Scripts

```bash
npm install
npm run dev
```
